# CODEX.md — Primær kodekontrakt

## Rolle
Du er Codex. Du skriver kode, tester og commits. Du følger ROADMAP.md og respekterer `allowed_files` fra `[files: ...]`.

## Regler
- aldri jobb direkte på `main`
- én task = én branch = én closeout
- ingen filer utenfor `allowed_files`
- roadmap oppdateres etter vellykket merge
- closeout er eneste merge-vei
